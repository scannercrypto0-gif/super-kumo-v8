## C2 · Context read contract

`aql.core.source-view.v1` in `src/aql/archive/source_view.py` consumes caller-pinned, already-normalized records in memory. The caller must load the records, rights receipts and pin manifest through verified Core custody. This function validates supplied evidence and emits no writes or promotion. Its hashes use existing archive canonicalization. Native writers, seals, wire types and archive schema majors are unchanged.

| Object | Required fields |
| --- | --- |
| Record | `key` nonempty logical slot ID, `version` positive integer, `prior` previous SHA-256 or null for version one, `source` pinned provider/product identity, `market` exact caller-pinned structured identity, `use` MONITOR_ONLY or DECISION, `grade` TEST_ONLY/RETROSPECTIVE_NON_PIT/PROSPECTIVE_UNATTESTED/PIT_ATTESTED, `value` non-null canonical JSON, `final` bool, `event_at,published_at,received_at,committed_at,known_at` UTC epoch ms or null, `witness` digest or null, `rights` pinned rights digest |
| Rights projection | `source`, `state` VERIFIED/DENIED/UNKNOWN, `uses` allowlist, `valid_from,expires_at` UTC epoch ms. This is a projection of an already-verified authorization decision. Original provider/version/terms, region, retention and use evidence remain in Core custody. Production callers must recheck current access/retention independently of historical cutoff. |
| Query | Ordered unique `expected_keys` from a frozen grid/cohort, `pins` mapping exact (key, version) to digest, `rights_by_digest`, `source,market,cutoff,max_age_ms,use`, optional `require_pit` |
| Result | `schema,source,market,use,cutoff,coverage,slots,digest`; slots preserve requested order and have `key,record,digest,reason`. UNKNOWN when none admitted, PARTIAL when some admitted, COMPLETE when all admitted. |

Only revisions both locally committed and known/published by cutoff can qualify, with unavailable clocks explicit. A pending future correction does not rewrite prior knowledge. Latest eligible-in-time denial/staleness is not repaired by falling back to a superseded value. Freshness here is receipt age; feeds must also declare publication/event age and cadence rules before activation. Required PIT uses externally verified chronology, not receipt or a self-issued hash. A TEST_ONLY fixture is never a decision input. MONITOR_ONLY cannot silently become an input to entry or exit rules. Decision mode is an evidence selector, not any operational eligibility. Event time may describe a scheduled future event if independently announced by cutoff; its actual future outcome requires a separate revision. Producer adapters remain future work where native contracts do not yet publish these records.

## C4/C5 · Consumer and fault evidence

Source → verified Core query → Scanner census/Discoverer context → Secretary existing receipt route → Factory trials/Lab evaluation. Return feedback links to immutable source refs. Discoverer/Factory/Lab release integration remains on their existing drafts. This change does not add a recipient or persistent delivery effect. Existing Generic H source/hash binding and #271 synthetic ACK/lost-ACK/restart scope are reused. A future exact release-tree join needs consumer adapters and separate deployment evidence. No Draft-to-main import.

The existing recovery fetch accepts a floating Retry-After value; malformed non-finite values could bypass cooldown. The focused fix normalizes malformed, non-finite and negative delays to the existing 60-second fallback. Offline tests inject a real HTTP 429 exception and verify no second transport call before expiry, including invalid headers; additional tests cover process-shared reserve, gap metrics, idempotent resume, stale/future revisions and replay. Existing draft evidence covers disconnect, gaps and clock rejection. Process-local budget is not shared-IP cross-process fencing. Operations must prove common fencing or sequential exclusivity, host clock/quotas and provider rights before real activation. Keep #286 untouched and #305 NOT_RUN.
