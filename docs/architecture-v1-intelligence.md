# Architecture v1 intelligence contracts

[Architecture](architecture-v1.md) · [Shared wire, types and delivery](architecture-v1-contracts.md#shared-types-and-delivery) · [Acceptance](architecture-v1-acceptance.md)

These are optional versioned capabilities. The Intelligence Gateway owns retrieval receipts; Factory owns model and experiment records; Lab independently assesses outcomes. Core holds approved sources and immutable revisions. AI/ML requests use research queues and Operations leases. Core ingestion, position protection, deterministic baselines and active traders never wait for these queues. Reuse existing Factory registries and ledgers and Core materialized views.

## Evidence and AI

`Uncertainty={kind:UNVALIDATED|CALIBRATED|UNKNOWN,level:LOW|MEDIUM|HIGH|UNKNOWN,probability:dec|null,calibration:Ref|null,limitations:text[]}`. CALIBRATED requires an eligible calibration receipt for the target, horizon and population. Confidence text alone never supplies a probability.

**EvidenceBundle.v1** · Core/Gateway → research clients. Input `{purpose:id,cutoff:ms,source_allowlist:Ref,freshness_policy:Ref,requester:id}`. Output `{bundle_id:id,cutoff:ms,entries:{fact_id:id,claim:text,value:text|null,unit:id|null,source:Ref,source_locator:text,rights:Ref,clock:SourceClock,revision:Ref|null,valid_until:ms|null,disposition:VERIFIED|DISPUTED|STALE|UNKNOWN,reason:id|null}[],coverage:Ref,uncertainty:Uncertainty}`. Search admitted internal as-of sources first, then permitted official providers, then optional model-assisted extraction. Keep separate factual citations, tool call/retrieval times and unresolved conflicts. A cited late revision cannot qualify prior evidence. Archive-based research may explicitly request retrospective outputs. Redisclosure requires per-entry rights. Test false citation, stale/conflicting inputs, rights mismatch and revision cutoff.

**AIRequest.v1** · Research consumer → Gateway/Factory adapter. Input payload `{request_id:id,requester:id,mode:RETRIEVE|RESEARCH|ANALYZE|CHALLENGE|ADVISE|BLIND_SHADOW,question:text,decision_context:Ref,baseline:Ref|null,protocol:Ref,evidence_bundle:Ref,as_of:ms,deadline:ms,prompt:Ref,output_schema:Ref,allowed_providers:Ref,allowed_tools:Ref,redaction:Ref,classification:PUBLIC|INTERNAL|RESTRICTED,max_attempts:uint,max_tokens:uint,max_tool_calls:uint,max_cost:dec,currency:id}`. Output acceptance is DeliveryReceipt; result is AIResponse. ADVISE may reference frozen baseline. BLIND_SHADOW requires baseline null and segregated access, including cache. Fingerprint includes prompt, policy, evidence, mode and output schema. Test disclosure, stale snapshot and missing budgets.

**AIProviderAdapter.v1** · Gateway dispatch → replaceable provider, receipt → Factory. Input `{request:Ref,lease:Ref,attempt_id:id,provider:id,model:id,model_version:id,adapter_version:id,parameters:Ref,tool_manifest:Ref,redacted_input:Ref,deadline:ms}`. Output `{attempt_id:id,state:COMPLETE|TIMED_OUT|RATE_LIMITED|REFUSED|FAILED|UNKNOWN,provider_request_id:id|null,resolved_model_version:id|null,started_at:ms,finished_at:ms,input_tokens:uint|null,output_tokens:uint|null,tool_calls:uint,cost:dec|null,currency:id,raw_output:Ref|null,failure:id|null}`. Immutable attempts, including fallback and estimated/reserved costs. Retry only transient within original total budgets, provider allowlist, rights/privacy and deadline. Unknown spend reserves full charge until reconciliation. Unpinnable model version disqualifies scientific comparisons requiring exact version. No provider/tool access to write surfaces, secrets, private strategy data or prior blind decision. Treat retrieved instructions as data; enforce allowlisted tool schemas/egress outside the model. Test injection, provider switch and quota exhaustion.

**AIResponse.v1** · Gateway/Factory → requesting component and Lab. Input `{request:Ref,attempts:Ref[],evidence_bundle:Ref,validation_policy:Ref}`. Output `{response_id:id,request:Ref,state:VALIDATED|PARTIAL|UNTRUSTED|UNKNOWN|EXPIRED,structured_output:Ref|null,citations:id[],uncertainty:Uncertainty,policy_checks:Ref,issued_at:ms,expires_at:ms,reason:id|null}`. Validate required schema, grounding, clock, rights, version and budget before use. Quarantine unsupported claims, malformed output and suspicious tool interactions. Retain original request, resolved provider/model, prompt, tool and result digests, with redacted replay evidence within rights. Replay verifies preserved receipts and comparisons; stochastic regeneration is a separate experiment. Test invalid schema, bogus citations and late result.

**AIAdvice.v1** · Factory advisor → opted-in research and Lab. Input `{response:Ref,baseline:Ref,opportunity_id:id,comparison_policy:Ref}`. Output `{advice_id:id,opportunity_id:id,baseline:Ref,assessment:AGREE|CHALLENGE|ABSTAIN,alternatives:Ref[],falsification:text,uncertainty:Uncertainty,expires_at:ms}`. Advisory only. Lab compares baseline alone, blind shadow and baseline+advice under frozen combination rules and the same universe. Invalid advice abstains. Test expiry and lack of permission effects.

**AIShadowDecision.v1** · Factory shadow → Lab. Input `{response:Ref,opportunity_id:id,sealed_context:Ref,blind_policy:Ref,freeze_receipt:Ref}`. Output `{shadow_id:id,opportunity_id:id,decision:BUY|SELL|WAIT|REJECT|UNKNOWN,entry:dec|null,stop:dec|null,targets:dec[],market:Market,reason:text,uncertainty:Uncertainty,frozen_at:ms,expires_at:ms}`. Freeze before observing baseline or outcome; Lab joins only after both decisions are immutable. Failed/late shadow slots remain in denominator. Costs, ambiguity, fills and misses use the same Lab policy. Test baseline leak, late tool retrieval and missing shadow.

## Machine learning

**MLFeatureSet.v1** · Factory feature builder over Core refs → trainers/inference. Input `{cohort:Ref,feature_spec:Ref,label_spec:Ref,as_of:ms,cutoff_policy:Ref}`. Output `{feature_set_id:id,dataset:Ref,rows:Ref,feature_definitions:Ref,label_definitions:Ref,availability_manifest:Ref,coverage:Ref}`. Rows contain `{row_id:id,opportunity_id:id,decision_at:ms,features:{name:id,value:dec|null,unit:id,source:Ref,clock:SourceClock,reason:id|null}[],label:{value:dec|null,outcome:Ref|null,window_end:ms,known_at:ms|null}}`. Feature keys unique. At inference, label unavailable by design. Training labels require window maturity and known-at by training freeze. Missing/imputed handling and fit population are declared; unknown critical values reject eligibility. Test future feature, revised source, premature label and regime-window leakage.

**MLTrainingRun.v1** · Factory → Lab and model registry. Input `{feature_set:Ref,protocol:Ref,code:sha,environment:Ref,algorithm:id,parameters:Ref,seeds:uint[],train:Ref,validation:Ref,sealed_test:Ref,embargo_ms:uint,baseline:Ref,budget:Ref}`. Output `{run_id:id,trial:Ref,state:REGISTERED|RUNNING|COMPLETE|FAILED|REJECTED|UNKNOWN,fit_artifact:Ref|null,metrics:Ref|null,started_at:ms|null,ended_at:ms|null,reason:id|null}`. Chronological nonoverlapping folds with purging of label windows crossing fold boundaries and embargo around held-out periods. Fit transforms only on train, tune on validation, freeze config before authorized sealed OOS. Record tuning attempts, environment, deterministic seeds and declared numeric tolerance when bitwise regeneration is unsupported. New tuning after test requires new untouched test. Test overlap, transform leakage, repeat-run identity and abort recovery.

**MLModelArtifact.v1** · Factory registry → opt-in inference and Lab. Input `{training:Ref,artifact_bytes:Ref,evaluation:Ref,release_policy:Ref}`. Output `{model_id:id,version:id,artifact:Ref,feature_schema:Ref,training:Ref,evaluation:Ref,previous:Ref|null,state:CANDIDATE|VALIDATED|APPROVED_SHADOW|PAUSED|REJECTED|RETIRED,model_card:Ref,activation_policy:Ref}`. Registry stores immutable versions and separate CAS activation pointer. Independent Lab acceptance requires predeclared incremental net utility, robustness, calibration and adequacy, plus reproducibility and Ops checks. Promotion is research/shadow only. Reject contaminated OOS or unsafe artifact formats. Test tampering, wrong feature schema and rollback to compatible previous pin or disabled state.

**MLInferenceResult.v1** · Factory inference → opted-in Lab/research. Input `{model:Ref,features:Ref,row_id:id,opportunity_id:id,as_of:ms,deadline:ms,policy:Ref}`. Output `{inference_id:id,model:Ref,features:Ref,state:AVAILABLE|ABSTAIN|UNKNOWN|EXPIRED,prediction:dec|null,unit:id,uncertainty:Uncertainty,generated_at:ms,expires_at:ms,reason:id|null}`. Validate pinned version, compatibility and temporal eligibility. No synchronous operational dependency. Test paused model, late result and missing required feature.

**MLMonitoringResult.v1** · Lab → Factory registry and Operations. Input `{model:Ref,baseline:Ref,inferences:Ref,outcomes:Ref,window:Ref,monitor_policy:Ref}`. Output `{monitor_id:id,model:Ref,state:HEALTHY|DRIFT|DEGRADED|INSUFFICIENT|UNKNOWN,feature_drift:Ref,performance:Ref,calibration:Ref,counts:Ref,recommended_action:KEEP|PAUSE|ROLLBACK|RETEST}`. Compare input drift, missingness, prediction drift, realized net metrics and calibration against frozen windows and matched baseline; insufficient mature labels cannot certify health. Factory pauses or rolls back to previous still-qualified pin on policy breach, preserving in-flight versions and stale-result rejection. Refit is a new experiment. Test drift with incomplete labels and rollback under concurrent inference.

## Asset Intelligence and event memory

Core materializes a read-only versioned dossier over its existing custody and versioned features. Technical BTC-first daily/ISO weekly/calendar monthly windows use UTC and final admitted bars. Store venue/quote basis explicitly. Factory runs the on-demand specialist using a preregistered bounded analysis. Trigger checks use admitted shared observations, a scoped lease and existing ledger; no additional continuous deep-analysis feed.

| Contract and owner → consumer | Input → output payload | Validation and transitions |
| --- | --- | --- |
| **AssetProfile.v1** · Core → Factory/Discoverer and research readers | `{asset_id:id,custody_manifest:Ref,cutoff:ms}` → `{asset_id:id,profile_version:id,prior:Ref\|null,markets:Market[],source_versions:Ref[],rights:Ref[],coverage:Ref,clock:SourceClock,cutoff:ms,permitted_modes:id[]}` | Keep stable asset vs market IDs, listing/coverage and revisions. Reject substituted BTCUSD/BTCUSDT or PAXG/gold identity. |
| **AssetFeatureSnapshot.v1** · Core → Factory/opt-in context | `{profile:Ref,query:Ref,feature_policy:Ref,cutoff:ms}` → `{snapshot_id:id,profile:Ref,features:{name:id,value:dec\|null,category:id\|null,unit:id,window:Ref,rule:Ref,source:Ref,clock:SourceClock,reason:id\|null}[],coverage:Ref,fresh_until:ms}` | Distinguish observed prices from derived MA/slope, S/R rules, volatility/drawdown and regime. Later macro inputs need lawful vintages, calendar/lag/freshness alignment. No wallet-identity or causal claims from proxies. |
| **AssetOutlook.v1** · Factory specialist → Lab/Discoverer/opt-in readers | `{profile:Ref,features:Ref,protocol:Ref,experiment:Ref,trigger:Ref\|null}` → `{outlook_id:id,parent:Ref\|null,profile:Ref,features:Ref,issued_at:ms,horizon_end:ms,valid_until:ms,scenarios:{name:id,condition:Ref,uncertainty:Uncertainty}[],falsification:Ref,triggers:{rule:Ref,kind:CHANGE\|INVALIDATION\|DEADLINE,confirmation:uint,cooldown_ms:uint,deadline:ms}[],uncertainty:Uncertainty,coverage:Ref}` | Immutable issuance; Factory appends VALID→REASSESSMENT_REQUIRED/STALE/INVALIDATED transition receipts. Key trigger dedupe by outlook version + rule + effective observation/deadline. No silent TTL extension. Evaluate hits, failures, no trigger/nonoccurrence and failed analogues in existing experiment ledger. |
| **AssetEventLink.v1** · Core event memory → Lab/asset readers | `{event:Ref,asset:Ref,subject:Ref,relevance:Ref,cutoff:ms}` → `{link_id:id,event:Ref,subject:Ref,relation:CONSULTED\|KNOWN\|RETROSPECTIVE,clock:SourceClock,rights:Ref,reason:id\|null}` | Event versions preserve announced/scheduled/actual clocks, cancellations and revisions. Event ref resolves `{event_id:id,version:id,prior:Ref\|null,kind:id,state:ANNOUNCED\|RESCHEDULED\|OCCURRED\|CANCELLED\|UNKNOWN,scheduled_at:ms\|null,actual_at:ms\|null,clock:SourceClock,source:Ref,rights:Ref}`. Prior decision references remain immutable. Query by event and by subject, and prove actual consultation separately from relevance. |

Reports disclose coverage, rights, uncertainty, expiry and lineage. Each consumer opts in through a pinned policy. Asset intelligence cannot edit Scanner outputs or risk decisions. Later links, revised events and source corrections are new evidence. Lab returns both negative and positive assessments through the same experiment and feedback contracts.
