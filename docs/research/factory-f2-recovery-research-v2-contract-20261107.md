# Factory F — F2 Recovery 24-attempt research v2 contract (2026-11-07)

Status: **owner provisional C; engineering only; G0/F5/trading NOT approved**. Existing Draft Factory PR #267. This is a new research-only receiver alongside the unchanged signed F5 and original 53-trial diagnostic.

## Why v2 is separate

Real Recovery proves ten Core source-backed 2024 BTCUSDT Spot 15m months (29,376 distinct source bars), two frozen Work235 strategy definitions, 20 strategy×month diagnostic evaluations, and February/August inventory-only ×2 UNKNOWN. It does **not** provide an independent 53-trial original Factory experiment ledger or February/August source bytes. Legacy `aql_factory_historical_rule_projection.evaluate_historical_rules` requires 53 historical trials; legacy Results Store experiment builder requires nonnull source SHA for all attempts. Neither may be bypassed by invented evidence.

Factory v2 therefore uses independently versioned `aql.factory.f.f2-recovery-research-input.v2`, `validate_recovery_research_input(packet)`, `run_recovery_research_v2(packet, store_path)`, and sealed `aql.factory.f.f2-recovery-research-report.v2`. It **reuses** the current canonical `StrategyDefinition`/indicator AST evaluators, bar-seal/grid verification, bounded Decimal fees/spread/slippage model, and next-open fill logic, but does **not** call the legacy 53-trial population validator or legacy F5 gateway.

## API and SQLite v2

`validate_recovery_research_input(packet)` returns `(definitions_by_id, verified_core_month_parents)` without mutating source/store. `run_recovery_research_v2(packet, store_path)` requires an **already existing, isolated SQLite layout-v2** store (owner/Integration creates with existing `migrate_store_v2(new_store_path)` before calling; never inside RAW/Warehouse). Returns signed report with `input_sha256,core_receipt_graph_sha256,scanner_receipt_sha256,lab_sha256,experiment_sha256,result_sha256,receipt_sha256,attempt_count=24,diagnostic_evaluated=20,feb_aug_inventory_unknown=4,modeled_count,unknown_count,costs,store_status`, all approval/ACKs null, trading NONE, Paper off, holdout sealed.

Factory additionally pins both exact Work235 original StrategyDefinition digests (`test_momentum@v1` = `5d293f892fd829a9d1c1d2933612bbb4f2d57b4445deefce06436959824cb55b`, `test_reversion@v1` = `d00ccc44f76785ffec3a17786b3f71303e6d6176809f8d96435c6f8e1c570a1e`). A resealed modified strategy with the same ID is rejected.

The distinct immutable SQLite `recovery_research_v2` table stores the **literal full 24-attempt census including four NULL source hashes**. Do not route that ledger through legacy `build_experiment` (non-null-only schema) or substitute surrogate source receipts. First exact packet => `STORED_IMMUTABLE`; rerun same packet => `REPLAY_IDENTICAL`; conflicting same experiment ID or changed DB bytes fail closed. Compare stable `lab_sha256,experiment_sha256,result_sha256` across runs. The *outer* `receipt_sha256` binds `store_status` and therefore changes first/replay; independently rehash each full report. The old SQLite experiment table and signed F5 workflow are untouched.

The v2 Lab evaluates the frozen strategy's causal confirmed-close entry/exit signals with next-open modeled prices, explicit operator costs, and `UNKNOWN` for any intrabar stop/target touch or unobservable exit. It does not infer trading fills or strategy performance; `source_original_bytes_verified=false` is implied by the local-only trust boundary.
