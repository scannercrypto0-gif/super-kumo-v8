# Factory #246 — Frozen historical StrategyDefinition rule projection

## Scope
**Factory-owned continuation of Draft PR #241**, stacked on #229 → #222. This is a price-bearing, deterministic and bounded research rule-projection **adapter**, not a new execution/backtesting platform. It invokes the already-merged `StrategyDefinition` typed grammar, `IndicatorRegistryV2` existing kernels (V1 and V2), and Factory `dec` monetary validation. It does **not** call old #222's closed P2 ten-bar engine for general Discovery strategies: #222 enforces one immutable breakout policy and fixed external proof SHAs; loosening it would invalidate the historical P2 evidence. Actual integrated execution-scoring acceptance remains blocked.

API: `research_wp_r0.aql_factory_historical_rule_projection.evaluate_historical_rules(packet)`
Input: `aql.factory.historical-rule-projection.v1`, sealed canonical JSON SHA256 `artifact_sha256`.
Output: `aql.factory.historical-rule-report.v1`, sealed canonical receipt, model-only / no authority.

## Inputs to Work and Core
- Required `research_window` pins `train_end_exclusive_ms`, an embargo of at least 3 days, and sealed holdout start/end. Every supplied bar must close **before** training ends; out-of-grid opportunities and holdout bars fail closed. This is a development-only test, not an OOS evaluation.
- Caller supplies a **read-only** source-pinned, gap-free price grid with `open_ms`, `close_ms`, OHLCV, `quality=FINAL`, `known_at_ms` or explicit null, and each bar's internal content-consistency digest over the other fields (not independent source proof). Grid interval is 1m, 15m or 1h.
- Source byte and source manifest SHA256 are **distinct commitments**: a caller-supplied digest never verifies original bytes, ZIP member SHA, actual custody lineage, or publication chronology. Core #245 has exclusive ownership of native ZIP/CSV normalization and independent chronology verification.
- `strategy` is the actual merged `StrategyDefinition.to_dict()` object, revalidated under `IndicatorRegistryV2`, with digest bound to the selected frozen candidate. This shape is compatible with the strategy definitions generated by Discoverer #230, though this branch does **not** import that unmerged owner implementation.
- Entire frozen 53-attempt trial ledger must be present with unique IDs, plan pins, candidate digests, and explicit duplicate parent references. No missing/extra attempt, premature `EVALUATED` state, or false result promotion. Full universe census separately conserves eligible/ineligible/rejected/unscanned/unknown/nominated; its independent completeness is explicitly `NOT_INDEPENDENTLY_ATTESTED`.
- Opportunity ledger is separately counted, and every supplied opportunity must carry exactly two unscored BASE/SHADOW slots. Zero independently connected opportunities is allowed, but **not** relabeled as complete market coverage.
- Cost-model fields explicitly separate entry/exit fee, spread, slippage and perp funding **assumptions**. Spot permits long research only (unlevered StrategyDefinition V1); perp may model long/short, but funding assumptions are not actual exchange funding, and liquidation/borrow execution effects are unmodeled. No OHLCV-inferred executable fills.

## Decision/event semantics
- First evaluate existing indicator kernels on the complete, digest-bound grid. For each decision at closed bar i, read only indicator values from bars at or before i. Lagged refs use i-lag; missing warmup is **WARMUP_UNKNOWN**, not a false no-signal. No time travel or gap fill.
- Entry rule true at closed i ⇒ **MODELED** entry at open[i+1]. Exit rule true at closed j ⇒ **MODELED** exit at open[j+1]. Holding cap in the original definition may also request a next-open exit. No overlapping modeled positions.
- Stop and target levels in StrategyDefinition are not implied order fills by OHLCV. If a held bar touches either threshold, model marks **UNKNOWN_INTRABAR_STOP_TARGET**, does **not** score a return and blocks subsequent path-dependent outcomes. Missing exit rule/warmup and end-of-grid stay NULL/UNKNOWN.
- The cost/return arithmetic is only a bounded paired price projection. It deliberately does **not** claim that the old P2 breakout execution engine has been generalized or re-run. It does not implement portfolio management, dynamic sizing, real fills, verified margin funding, execution latency, or infer statistical significance.
- Source `ORIGINAL_UNVERIFIED` and missing `known_at_ms` remain `RETROSPECTIVE_ONLY_UNVERIFIED`. Even a nonnull known-at supplied by caller cannot assert independently verified historical PIT. All outputs: `historical_pit_verified=false`, `source_original_bytes_verified=false`, `scientific_result=INSUFFICIENT_EVIDENCE`, `trading_authority=NONE`, `holdout=SEALED_UNOPENED`.
