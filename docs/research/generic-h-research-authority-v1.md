# Generic H research authority v1

Decision [B and the scoped follow-up](https://github.com/scannercrypto0-gif/super-kumo-v8/pull/271#issuecomment-6738730838).

The existing Generic H Integration bridge accepts an explicit lane on its research-result entry point. Omission preserves the legacy durable WAIT behavior. The Scanner F3 signature verifier and signed activation route are unchanged.

| Requested lane | Result in Generic H v1 |
| --- | --- |
| EXPERIMENTAL | An unsigned, sealed classification for a checked retrospective diagnostic. The typed path never writes to Secretary. |
| RESEARCH_VALIDATED | Automated blocked disposition with reason `PIT_OOS_VALIDATION_EVIDENCE_UNAVAILABLE`; effective lane stays EXPERIMENTAL. |
| LIVE or PAPER | Rejected before research processing. Owner-only LIVE permission and order safety checks belong at the separate operational order boundary. |

The caller must supply operator-controlled dataset permission configuration and an already authorized warehouse location. Construct the configuration from a trusted deployment or runner context, independently of the packet and research result. Its exact fields are dataset_id, version, source_bytes_sha256, manifest_integrity_sha256, query_sha256, decision_cutoff_ms, rights_reference and valid_until_ms. The reference must identify an applicable permitted-use record. This API does not adjudicate rights or authenticate the configuration's supplier. Never populate it from candidate-controlled JSON. This is dataset permission, not per-strategy approval.

Acceptance uses the existing Scanner and Factory checks for sealed lineage, causal closed bars, code and configuration identity, and seven declared Spot costs. Immutable Core readback must match the input. The existing Core builder checks linked results and authority fields without a write. No typed receipt is operational permission or an enqueue request.

The Generic H producer explicitly supplies descriptive in-sample NON_PIT evidence with a sealed holdout. Positive automated validation requires a separate existing or future verified evidence producer with a frozen policy covering PIT/as-of, train/embargo/holdout, leakage, cost realism, risk caps, reproducibility and selection bias. This change sets no thresholds and never promotes Generic H diagnostics. Integrate that producer before claiming positive RESEARCH_VALIDATED support.
