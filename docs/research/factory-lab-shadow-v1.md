## Input and execution

- **Lab dossier** `aql.factory.lab-shadow-dossier.v1` binds LAB origin, distinct baseline and Shadow identities (ID/version/code/parameters), hypothesis and falsification, counterexamples, category, market, candle and holding horizon, dependency evidence, DECISION and MONITOR_ONLY attachment hashes, and optional prior admission. Attachments are canonical JSON content-addressed by Factory's existing digest, including JSON-encoded source code when provided. The adapter never runs untrusted attachments or lets MONITOR_ONLY affect signals.
- **Independent protocol** `aql.factory.shadow-protocol.v1` binds category/market, independent evaluator and protocol custodian identities, freeze, chronological train/validation/evaluation/final holdout, label-horizon embargo, step, baseline exit and all four standard families. It freezes primary diagnostic, minimum pairs, effect margin, alpha, family-test correction and exact taker/passive/stress cost assumptions. No generic thresholds are silently selected for categories. Role names are checked for obvious self-approval. Operational authenticity must come from independently provisioned pins and actor custody.
- **Cohort** `aql.factory.shadow-cohort.v1` binds source hash, evidence grade, immutable decision universe, all attempts, matched entries, bar data and optional native Factory receipt ref. Cohort and other pins must arrive independently from custody. The bounded entry adapter consumes already emitted decisions or generated fixtures. It does not re-run strategy code or claim a native original-source join from an opaque receipt ref. Freeze and window validation cannot attest when an external dataset or protocol was actually available. No evaluation or historical promotion with fake PIT or an opened final holdout.
- **Admission** `aql.factory.shadow-admission.v1` is independently persisted before evaluation. Wrong hash, category, code/parameter attachments, cohort, time or role returns machine-readable `RETURN_TO_LAB`. A corrected submission cites the persisted rejected receipt and increases the Shadow version, keeping the same baseline. Replays preserve the exact attempt and result payloads. A conflicting result on the same Shadow identity fails closed. Read-only parent lookup and the native transaction use the same isolated Factory v2 store.
- **Evaluation** `aql.factory.shadow-evaluation.v1` preserves the attempt ledger, separate opportunity and matched-entry counts, baseline results and all applicable families across taker, passive-entry/market-exit and stress. Full cohort rows retain rejection, nonfill and UNKNOWN. A paired sign test with two-sided family-adjusted p-value compares the preselected taker family against the pinned baseline exit on matched entries. Missing outcomes, small sample and ties can be inconclusive. This is a conditional exit diagnostic, with no economic claim or optimized winner. Keep sign-test independence, regime sampling, authentic out-of-sample custody and genuinely untouched test data as future scientific admission prerequisites. Fixture PASS/FAIL/INCONCLUSIVE is explicitly engineering-only. Public verdict BLOCKED retains bounded observation and gives no Paper eligibility.
- **Stop semantics** Fixed stop remains unchanged. Trailing stop starts at the frozen initial risk and ratchets to max(previous stop, completed bar high × (1 − trail fraction)), effective next bar. Targets use fixed R levels and preregistered allocation. Within a bar that reaches stop and target, the order is UNKNOWN. STOP_LIMIT fill remains UNKNOWN. Any interior gap before exit is UNKNOWN. Explicit passive zero/partial/unknown quantities are fixtures, with no OHLC touch-to-fill inference. Partial exits weight the reused round-trip cost kernel by each closed fraction, charging each fraction's entry/exit costs once. Model-only rows carry itemized fees, spread and slippage. Aggregate returns and close-only drawdown remain null if needed rows are unknown.
- **Promotion handoff** `aql.factory.shadow-promotion-handoff.v1` is the immutable small JSON contract posted above. Parse bounded bytes without duplicate keys or nonfinite constants and bind the independently pinned digest. Applicable family with an incomplete aggregate carries null result hash and `UNKNOWN_COUNTERFACTUAL_COVERAGE`; the evaluation receipt still binds full raw results. Excluded family carries the frozen reason and null result hash. Complete modeled family has its result digest and null reason. No selection is issued for LIVE. A future eligible LIVE recommendation must freeze exactly one applicable method under separate Package 2 and owner authority.
