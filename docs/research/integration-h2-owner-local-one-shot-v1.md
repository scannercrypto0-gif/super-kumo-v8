## Four gates and stop rules

**G0 / immutable code isolation:** Local Git must already possess all five exact commits; no download, pip, branch rewrite or implicit HEAD. Uses `git archive` with deterministic role overlay order and an isolated Python interpreter. File-level SHA of the staged overlay and current operator are returned in the evidence; includes the frozen Work235 fixture. A missing or mismatched commit/file fails before reading original source.

**G1 / original-source verification:** Only after a valid external MAC and safe path check is any original directory enumerated. Pre/post SHA-256 fingerprint both source trees. Fail on symlink, uncheckpointed SQLite WAL/SHM/journal, unsafe output root, missing rights/receipt, Core245 native receipt identity, Core253 `query_local(...,require_complete=True,sqlite_immutable=True)`, SHA/manifest/cutoff mismatch, missing bars or UNKNOWN coverage. The Core245 digest is **not** an alias of the bounded Core253 query digest. Never mutate or repair original RawVault/Warehouse. The retained Core245 receipt must itself be independently authenticated as part of custody; matching JSON hash alone does not establish origin. 

**G2 / one generic limited run:** Reuse Scanner manual AST plugin, immutable readback, causal signal batch, Factory H generic Decimal next-open model, existing immutable Factory Results SQLite v2, independent Lab, replay-identical, and existing Core Secretary durable WAIT with null ACKs. Source, role code, cost inputs and outputs are each kept distinct; results file must be a fresh SQLite outside source. This is historical *NON_PIT* engineering only, with no paper/live fills.

**G3 / sanitized local Audit:** A single SHA-sealed JSON receipt contains status, stop reason, role/code hash, Core245/Core253 digests, coverage counts, Scanner/Factory/Lab/Secretary parent hashes, replay and no-write fingerprint. No original path/price bars, secret MAC or HMAC key in this receipt. On absent permission, the correct state is `WAIT_SOURCE_PERMISSION`; on failure `BLOCKED`; `EXPERIMENT_ENGINEERING_PASS` is valid only after the actual local G0–G2 sequence succeeds. Source rights and owner signer identity still require external independent governance; receipt does not certify economics or PIT.
